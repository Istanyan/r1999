## 一、本次运行复现的问题

### 1. 弹窗堵死（最高优先级）

**现象**：启动时"谋·朱然限时返场"弹窗挡住主界面，脚本启动清理 `dismiss_popups` 点了 fanhui.png 但没关掉弹窗（弹窗皮肤与模板不一致，或点击位置偏移）。脚本不清弹窗就直接导航，导致：
- 活动场入口找不到 → 蛋糕小游戏失败
- 征战天下入口找不到 → 征战天下失败
- 演武入口找不到 → 全部任务连续失败3次跳过
- 空等5轮×30秒后脚本退出（完成0，剩余0）

**根因**：
- 启动清理只做固定轮次，不循环检测主界面标志（chengzhang）
- 活动弹窗没有专门模板，靠 fanhui.png 硬退，皮肤换了就失效
- 任务连续失败后没有"强制清弹窗→重试"的恢复机制，直接放弃

**run5完整失败链**：
```
启动 → 弹窗未关 → 找活动场失败 → 蛋糕失败×2 → 合成大将军失败
→ 征战天下找不到入口 → 连续失败3次跳过 → 成长模块（也找不到入口）
→ 空等1/5 → 空等2/5 → 空等3/5 → 空等4/5 → 空等5/5 → 退出
```

### 2. 张春华模板匹配失败导致卡死

**现象**：征战天下→急报→选将界面（贪欲之壑，单镜框），需要选张春华。
日志：`选将不完全: 单镜框 应选1名，仅点中0名！`

**根因链**：
1. `张春华.png` 模板匹配失败（可能游戏UI更新后模板过时，或卡片灰显/带锁）
2. `click_if_found` 找不到模板静默返回 False，不打日志
3. `_zz_select_characters` 返回 placed=0
4. 代码不检查选将结果，直接进入 `_zz_battle_flow` 点开战
5. 开战按钮点了但因为没选武将，游戏无反应
6. 脚本进入轮询循环，每10秒点一次"空白处.png"等待战斗结束
7. 死锁：轮询点空白处误选了袁绍/华佗/荀彧，武将选上了但脚本认为已开战，不会再点开战
8. 空转10分钟才退出

**关键代码缺陷**：
```python
# _zz_select_characters 返回 placed=0，但调用方不检查
if placed < len(names):
    _warn(f"选将不完全: ...仅点中{placed}名")
# 没有 return False / abort，继续往下走
```
