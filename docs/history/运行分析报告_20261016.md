## 二、发现的问题

### 问题1：运行中弹窗未处理（最严重）

**现象**：游戏过程中不断弹出活动弹窗，脚本只在启动时清理一轮：
- 签到奖励弹窗
- "秋日好礼"活动弹窗（10.11-10.16）
- "谋·朱然 限时返场"弹窗（10.11-10.16）

**影响**：
- 弹窗挡住主界面后，所有导航（活动场、征战天下、成长）全部失败
- 脚本在弹窗上盲点，浪费时间
- 需要人工介入关闭弹窗

**根因**：启动清理只做固定轮次，运行中任务间隙没有检测弹窗。

### 问题2：急报打完后返回层级错误

**现象**：急报战斗结束后（"痴念之响"打完），脚本点 fanhui 想返回演武界面，但一路退到了游戏启动画面（"开始游戏"按钮）。

**影响**：
- 游戏完全退出到登录界面
- 需要手动点开始游戏重进
- 重进后所有状态丢失，后续任务全部失败

**根因**：打完急报后的返回逻辑没有确认当前页面层级，盲目点返回。应该在每次返回后检查是否到达目标页面，而不是连续点。

### 问题3：合成大将军对局中盲点点不到

**现象**：合成大将军对局中，脚本持续点击 (260, 845)，但签到弹窗和活动弹窗弹出后挡住游戏区域，脚本仍然盲点。

**影响**：对局被弹窗打断，无法正常进行。

### 问题4：蛋糕模块正常

**第一次运行结果**（重进游戏前）：
- 释放53个，95.9s正常结束
- 领奖全流程成功（领奖g 0.724 → 领取g 1.0 → 确定 → 两次返回）
- 与 run33（52个）持平

## 三、建议修复

1. **运行中弹窗清理**：在每个任务间隙和对局中，增加弹窗检测循环——持续点返回直到检测到主界面标志
2. **急报后返回**：打完急报后不要连续点返回，每次点完后截图确认当前页面，逐级返回
3. **活动弹窗模板**：为"秋日好礼"、"谋·朱然"等限时活动弹窗添加关闭模板
4. **合成大将军对局中**：增加弹窗检测，发现弹窗时暂停对局操作，先清理弹窗
